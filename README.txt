TradeDesk Admin Interface

Open index.html in a browser, or upload index.html to the root of a GitHub Pages branch.

Features:
- Responsive overview dashboard
- Users, deposit requests, withdrawal requests, trades, reports, activity log
- Search and status filters
- Local-only status actions and CSV export
- No login or password

Important:
This is a frontend-only interface using illustrative sample records. It is not connected to a broker, bank, payment processor, or live trading account. Changes are temporary and reset on refresh. Do not use sample balances or transaction records as evidence of real funds. A production deployment needs secure server-side authentication, authorization, audited APIs, and proper financial controls.
